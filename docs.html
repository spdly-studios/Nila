Getting started

How Attendly works

Mark attendance, submit the register, and Nila contacts the parents of absent students through the secure server relay.

Daily workflow

  1. Choose a class and mark each student present or absent.
  2. Select Submit & start calls.
  3. Review call outcomes, transcripts, timelines, and quality scores in Call history.
  4. Use Insights to identify recurring absence patterns.

Supported classes

8-A, 7-B, 10-C, and 6-A are included in the starter roster. Students can be added from the Attendance page.

Nila + SnapServe

Voice follow-up

Nila starts in Tamil, confirms the parent or guardian, asks the absence reason, records a concise disposition, and escalates emergencies or safeguarding concerns for human review.

Call outcomes

absence_confirmedcallback_requestedhuman_follow_upno_answer

Privacy

SnapServe credentials stay on the relay server. The browser receives stored call results and never receives the API key. Avoid entering unnecessary medical details.

Operations

Relay configuration

Set SNAPSERVE_API_KEY, PUBLIC_URL, ALLOWED_ORIGIN, and the optional webhook and AI variables in the deployment environment.

Health and status

/health is the deployment health check. Status dashboard shows live in-process traffic and service configuration.

Data endpoints

GET /api/calls, GET /api/attendance, GET /api/diagnostics, and GET /api/status are provided by the relay.
